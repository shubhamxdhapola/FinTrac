# 💰 FinTrac — Expense Tracker App

**FinTrac** is a personal finance management web app built with the **MERN stack**, **Redux**, and **Tailwind CSS**.  
It helps users efficiently track their **income and expenses**, manage budgets, and visualize financial data through **charts and graphs**.

## 🚀 Live Demo
🔗 [https://fintrac-izsk.onrender.com/](https://fintrac-izsk.onrender.com/)

---

## 🧩 Features

- 🔐 **User Authentication** — Secure login and signup using JWT & cookies  
- 💸 **Expense Management** — Add, edit, delete your daily expenses  
- 💰 **Income Management** — Record and track multiple income sources  
- 📊 **Data Visualization** — View your income vs expense trends using charts  
- ⚡ **Responsive UI** — Clean and mobile-friendly interface built with Tailwind CSS  
- 🗂 **Redux State Management** — Global state handling for seamless user experience  

---

## 🛠️ Tech Stack

### **Frontend**
- React.js  
- Redux Toolkit  
- Tailwind CSS  
- Axios  
- Recharts (for graphs and charts)

### **Backend**
- Node.js  
- Express.js  
- MongoDB (Mongoose)  
- JSON Web Token (JWT) for authentication  
- Cookie-based sessions
